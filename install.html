EMS — Expense Management System

This page explains how to install EMS on your Android phone. The application itself remains at the home page.

Open EMS

Install on Android

  1. Open the EMS home page in Google Chrome.
  2. Open Chrome's three-dot menu.
  3. Choose Install app if it appears. If only Add to Home screen appears, you can use that shortcut while installation support is being verified.
  4. Launch EMS from your home screen. Sign in with the same account to sync cloud records.
Important: Installation does not make the database work offline. Internet is required for sign-in and syncing. Do not clear browser storage unless you know your Supabase URL and public client key; these are currently saved in the browser on each device.

Current scope

This release keeps the existing purchase-entry, inventory, reports and authentication features. Do not assume it includes verified live retailer prices, automatic checkout, or a fully tested database migration.
